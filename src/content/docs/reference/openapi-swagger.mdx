# Swagger & OpenAPI Documentation

The UltraFast Shortener backend includes an embedded **Swagger UI** to interactively test endpoints, inspect JSON schemas, and review response status codes.

---

## Accessing Swagger UI

Navigate to:
[http://localhost:8080/swagger/index.html](http://localhost:8080/swagger/index.html)

Or download the raw OpenAPI 3.0 specification:
`http://localhost:8080/swagger/doc.json`

---

## Interactive Features

- **Try it Out**: Execute real HTTP calls directly from your browser.
- **Header Authorizations**: Input your JWT Bearer token or `X-API-Key` to test protected routes.
- **Request Models**: Inspect data types, validation rules, and examples for every request parameter.
